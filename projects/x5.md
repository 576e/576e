# X5 Group · Аналитика опросов сотрудников

[← К профилю](../README.md)

**Power BI · Опросы · eNPS · Сравнение подразделений**

## Задача

Представить результаты опросов в удобном для анализа виде: сравнить подразделения, рассмотреть оценки условий работы и руководства, выделить темы для дальнейшего изучения.

## Мой вклад

На стажировке в Paper Planes участвовал в командном проекте X5 Group: создавал визуализации показателей по категориям. Отдельный дашборд по опросам — удовлетворённость по подразделениям и причины оценок — разработал самостоятельно.

## Структура текущего дашборда

| Страница | Содержание |
| :--- | :--- |
| Обзор | Число респондентов, eNPS, доли промоутеров и критиков, намерение продолжать работу |
| Работа и руководство | Обратная связь, признание результатов, обучение и рабочая нагрузка |
| Условия и вознаграждение | Оценки оплаты, льгот, рабочего места и отношения к компании |
| Культура | Осведомлённость о ценностях, миссии, видении и стратегии |
| Кластеры | Распределение участников по кластерам и профиль оценок |
| Подразделения | Сопоставление подразделений и групп участников |
| Факторы | Средние оценки и разброс ответов по атрибутам |

Иерархические фильтры позволяют уточнять подразделение и рассматривать показатели в выбранном срезе.

## Аналитический подход

- Сочетаю сводные показатели с распределениями ответов: одно среднее значение не показывает различия между группами.
- Сравниваю оценки по темам и подразделениям, учитывая контекст выбранного среза.
- Использую среднее и разброс как описательные характеристики. Различия на графике сами по себе не доказывают статистическую значимость или причинную связь.

## Результат

Результаты опроса собраны в семь тематических страниц с общей навигацией и фильтрами. Отчёт помогает исследовать различия в восприятии работодателя и формулировать вопросы для более глубокого анализа.

Здесь опубликовано описание аналитической задачи и структуры отчёта без индивидуальных ответов сотрудников и внутренних результатов опроса.
